- 프로젝트 개요✨
    1. **계좌 생성, 조회, 삭제**: 사용자가 원하는 계좌를 만들고, 계좌의 정보를 확인하거나 삭제할 수 있는 기능을 제공합니다.
    2. **입출금 기록 관리**: 각 계좌에 대해 입금, 출금 같은 거래 기록을 남기고, 기록을 조회하거나 삭제할 수 있습니다.

```mermaid
graph TD
  subgraph 사용자 인증
    A1[회원가입 요청] --> A2[유효성 검사 & 중복 체크]
    A2 --> A3[DB 저장]
    A3 --> A4[회원가입 완료 응답]

    B1[로그인 요청] --> B2[사용자 조회]
    B2 --> B3[비밀번호 검증]

  end

  subgraph 계좌 기능
    C1[계좌 생성] --> C2[초기 잔액 입력]

    C3 --> C4[계좌 조회/삭제]
  end

  subgraph 거래 기능
    D1[거래 추가 요청] --> D2[금액, 유형, 설명 입력]

    D3 --> D4[거래 내역 조회]
  end

  subgraph 분석 기능

  end

  subgraph 알림 기능

  end

  A4 --> C1
