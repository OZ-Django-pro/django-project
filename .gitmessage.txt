# ✍️ 커밋 메시지 템플릿 (Gitmoji 스타일)
# 커밋 제목 첫 줄 (한 줄 요약 - 50자 이내)
# 예: ✨ feat: 로그인 기능 구현

# 본문 (선택) - 무엇을, 왜 변경했는지 설명
#
# 관련 이슈 (선택)
# 예: Closes #12

🔧 타입 (아래 중 선택):
✨ feat     : 새로운 기능 추가
🐛 fix      : 기능 수정, 버그 수정
💡 chore    : 코드 변경 (기능 추가 X, 주석/오타 등)
📝 docs     : 문서 수정 (README 등)
🚚 build    : 빌드 관련 설정 변경
✅ test     : 테스트 코드 추가/수정
♻️ refactor : 코드 리팩터링
🚑 hotfix   : 긴급 수정
